# 📊 CPS Unemployment Analysis — Root Causes of U.S. Socioeconomic Divide

I uncovered shocking patterns in U.S. unemployment using free Census data and Python. This project explores how age, gender, education, race, and geography contribute to America's socioeconomic challenges.

##  What This Project Reveals
- Which states have the highest unemployment
- How education level impacts job status
- Age groups most affected by unemployment
- Gender and racial disparities in labor force participation

##  Tools & Libraries Used
- Python (Google Colab / Jupyter Notebook)
- Pandas
- Matplotlib
- Seaborn
- Requests

##  Files Included
- `cps_unemployment.csv` — Raw data from the U.S. Census CPS API
- `analysis.ipynb` — Python notebook with data cleaning, visualization, and insights
- `charts/` — Folder containing generated visualizations (optional)

##  How to Run
1. Clone this repo:  
   `git clone https://github.com/yourusername/cps-unemployment-analysis.git`
2. Open `analysis.ipynb` in Google Colab or Jupyter
3. Run all cells to reproduce the charts and findings

##  Key Insights
- Education strongly correlates with employment status
- Youth and seniors show higher unemployment rates
- Some states and racial groups are disproportionately affected
